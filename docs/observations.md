# Retained observations, not a deployment benchmark

Eight selected field frames were reviewed with manual reference marks. A nearby candidate was reported in each. This procedure answers a narrow reference-assisted question and does not establish blind precision/recall or general accuracy.

A separate operator-cued selection check succeeded in two of four paired observations. It is a different task and unit, not an additional denominator for the eight-frame finding. The scans also produced competing candidates.

The original output images preserve those distinctions. Their embedded source labels are historical annotations, not independently verified distance measurements. No new labels, scores, positions or overlays were added for this account.

A recovered checkpoint matches a retained model-reference digest. A second checkpoint has a different digest and its relationship to the training run remains unresolved. Neither file is included, loaded, converted or executed by this repository.

The [recovered training report](training-report.md) adds historical four-class validation results and a static comparison of the notebook with the checkpoint's stored 50-epoch metric history. Those validation metrics are separate from the field observations above. They are not drone-only accuracy, new inference acceptance, or a held-out test result.

No new training, field run, model comparison, autonomous selection, position validation or live-phone deployment was performed. No rendered detection video or accepted training-curve image was established among the inspected artifacts. The available visual evidence is supplied rather than replaced with a reconstructed demo.
